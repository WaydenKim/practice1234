# 오늘의 영어

브라우저에서 바로 여는 영어 학습 페이지입니다. 단어 카드, 퀴즈, 자주 쓰는 표현을 한 파일에서 연습할 수 있습니다.

## 실행

`english.html`을 더블클릭하면 기본 브라우저에서 열립니다.

## 구성

- **단어 카드**: 카드를 누르면 뜻과 예문이 나옵니다. 이전/다음으로 단어를 넘깁니다.
- **퀴즈**: 한국어 뜻에 맞는 영어 단어를 고릅니다. 끝나면 맞힌 개수를 보여 줍니다.
- **표현**: 자주 쓰는 영어 문장과 한국어 뜻을 나열합니다.

## 단어와 표현 바꾸기

`english.html` 안의 `words`와 `phrases`를 수정하면 됩니다.

```javascript
const words = [
  { en: "appreciate", ko: "감사하다", ex: "I appreciate your help." }
];

const phrases = [
  ["How's it going?", "어떻게 지내?"]
];
```
